# Licence: choose one before publishing

This repository has no licence yet. Pick one, then replace this file with a file named `LICENSE` that holds the full licence text. GitHub shows the licence on the repository page and the Marketplace listing.

## Recommended

- **MIT.** Short and permissive. Anyone can use, change and redistribute the action, including inside closed-source pipelines, as long as they keep the copyright notice. The most common choice for GitHub Actions.
- **Apache-2.0.** Also permissive. Adds an explicit patent grant and requires changed files to say they were changed. A good fit if NeauraBuild wants the patent terms written down.

Either one lets customers copy or fork the action, which some security teams do before they allow a third-party action.

## Not recommended for this repository

- GPL or AGPL. Some customers' legal teams block copyleft code in their pipelines.
- No licence at all. Without one, nobody else may legally copy or change the code, and some customers' policies forbid using it.

## What to do

1. Choose MIT or Apache-2.0.
2. On GitHub, Add file, Create new file, name it `LICENSE`, and choose the template. Or copy the text from https://choosealicense.com.
3. Set the copyright line to the company that owns the code, with its exact registered name, for example "Copyright 2026 <registered company name>".
4. Delete this file.

The licence covers this action's code only. The Pramaan product and the collector the action downloads keep their own terms.
